FLORAREHBERI - GRUP 8
=====================

Dosyalar:
- index.html: Ana sayfa
- hakkimizda.html: Proje hakkında
- ansiklopedi.html: Bitki kartları, kategori filtresi ve anlık arama
- aranjman.html: Etkileşimli buket ön izlemesi
- iletisim.html: Form ve JavaScript doğrulaması
- css/style.css: Ortak tasarım
- js/: JavaScript ve jQuery etkileşimleri

ÇALIŞTIRMA:
1. ZIP dosyasını çıkarın.
2. FloraRehberi klasörünü VS Code ile açın.
3. index.html dosyasına sağ tıklayıp Open with Live Server seçin.
4. İnternet bağlantısı açık olmalıdır; Bootstrap, Bootstrap Icons, jQuery ve fotoğraflar CDN üzerinden yüklenir.

NOT:
Bu proje frontend örneğidir. Form gönderimi, sipariş, ödeme ve veri kaydı yapılmaz.
Fotoğraflar Unsplash görsel bağlantılarından yüklenir.
